# Chord Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or superpowers:executing-plans
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the diatonic chord row with a three-tier chord map (secondary
dominants, diatonic, borrowed) whose chords, including out-of-key ones, drive the
fretboard in every view.

**Architecture:** A new `SpelledNote` type and `spellChord` in `src/theory/notes.ts`
give letter-correct chord spelling. A new pure module `src/theory/harmony.ts` builds the
chord map from a key-relative `ChordRef`. The marker builders (`chordTones.ts`,
`chordShapes.ts`) accept any map chord and flag out-of-key tones with `isOutsideKey`,
which `NoteCircle` draws as a dashed ring. `ChordMap` (+ `ChordMapCard`,
`ChordRowModeToggle`) replaces `DiatonicChords`, and `App.tsx` swaps
`selectedChordDegree` for `selectedChordRef`.

**Tech Stack:** React 19, TypeScript 6 (strict), Tailwind 4, Vitest 3 + React Testing
Library (fast tier), Playwright (slow tier, CI only).

**Spec:** `docs/superpowers/specs/2026-10-20-chord-map-progression-player-design.md` —
this plan covers **PR 1 (Chord map)** only: Design sections 1–4, their fast-tier tests,
`tests/e2e/chord-map.spec.ts`, and the vision-doc "Future" entry. Meter, metronome,
progression storage, player hook, progression UI and dnd-kit are a separate plan.

## Global Constraints

- Theory logic lives only in `src/theory/`. Views and components must not compute
  chords, spellings or markers inline.
- Every non-trivial theory module has a matching `.test.ts`; components get a
  `.test.tsx` (jsdom, RTL).
- `type` aliases over `interface`; named exports (default export only for the top-level
  React component, i.e. `App`).
- Components stay under ~150 lines.
- Tailwind classes only: no new inline `style={…}`, no hex/rgb in JSX. Colors come from
  `src/index.css` tokens (`var(--color-fg-primary)` as an SVG attribute is fine, as the
  existing characteristic ring does).
- Tests over registries iterate the registry (`MODES`, every key offered by
  `KeySelector`, `CHORD_TIERS`) instead of enumerating items.
- `SpelledNote` = `` `${Letter}${"" | "#" | "##" | "b" | "bb"}` `` (35 values);
  `NoteName` is deleted.
- `ChordRef = { tier: "secondary" | "diatonic" | "borrowed"; degree: number }` (1–7;
  secondary: degree of its target). Default selection `{tier: "diatonic", degree: 1}`.
- Cards: `data-testid="chord-card"`, `data-tier`, `data-degree`,
  `aria-pressed`. ＋ button `aria-label` = `"Add <symbol> to progression"`. Note
  markers: `data-outside-key` when out of key.
- `ChordMap` must accept `onAdd?: (ref: ChordRef) => void` and render the ＋ button only
  when it is given (PR 2 wires it). App does **not** pass `onAdd` in this PR.
- Keyboard: `1`–`7` select `{tier: "diatonic", degree}` (pressing the selected one
  clears it); `t`/`s` unchanged.
- No new dependencies in this PR.
- Before every commit: `npm run lint`, `npx prettier --write <touched files>`,
  `npx tsc -b`, `npm test`. The husky pre-commit hook re-runs lint-staged, tsc and
  vitest. **Never** add Playwright to pre-commit; `npm run test:e2e` is CI-only (run it
  locally once in Task 7 if a browser is installed).
- Out-of-key ring: dashed, `stroke="var(--color-fg-primary)"`, never the gold
  `--color-characteristic` ring.

## Review Focus

1. **Extreme keys** (e.g. A♯ Lydian, whose vii is G𝄪m): the letter-correct V7/vii would
   be D𝄪7 with an F♯𝄪 (triple sharp). Expected: the map still renders; that chord is
   respelled from the enharmonic root (E7 = E G♯ B D) instead of throwing. Pinned in
   Task 2 (`"A# Lydian: V7/vii respells D##7 from its enharmonic E"`) plus the every-key
   × every-mode sweep.
2. **Selection whose cell empties after a key/mode change** (V/♭VII in C Mixolydian,
   then switch to Ionian, where vii is diminished). Expected: the selection is cleared
   and does not silently reappear when switching back. Pinned in Task 6
   (`"clears a selection whose cell empties after a mode change"`).
3. **Detour through the "All" key**: the All key resolves no chord, but the user expects
   their chord to still be selected when they pick a key again. Pinned in Task 6
   (`"keeps the selection through a detour via the All key"`).
4. **Out-of-key tone on a muted string or with its Legend role switched off**: expected
   to behave like any chord tone (muted / demoted to `scale`) while keeping
   `isOutsideKey`, and the clashing key letter stays hidden. Pinned in Task 3
   (`"keeps the out-of-key tone muted on a disabled string"`,
   `"demotes the out-of-key tone to scale when its role is toggled off"`).
5. **Chord/row-mode mismatch reaching Chord Shapes** (a 4-note chord with
   `mode: "triads"`, or the reverse, for one render while state settles). Expected: no
   markers and no crash. Pinned in Task 3
   (`"returns [] for a 4-note chord in triads mode"` and the 3-note/sevenths twin).

```ts
const LETTERS = ["C", "D", "E", "F", "G", "A", "B"] as const;
type Letter = (typeof LETTERS)[number];
type Accidental = "" | "#" | "##" | "b" | "bb";

// A letter-correct note name: one of 7 letters plus at most a double
// accidental (35 values). Every scale and chord speller returns this type.
export type SpelledNote = `${Letter}${Accidental}`;

const LETTER_PITCH: Record<Letter, number> = {
  C: 0,
  D: 2,
  E: 4,
  F: 5,
  G: 7,
  A: 9,
  B: 11,
};

// Spells `targetPitch` (0-11) on `letter`, adding the accidentals needed.
// Throws when that would take more than a double sharp or double flat.
function spellOnLetter(letter: Letter, targetPitch: number): SpelledNote {
  let delta = (targetPitch - LETTER_PITCH[letter] + 12) % 12;
  if (delta > 6) delta -= 12;
  if (Math.abs(delta) > 2) {
    throw new Error(
      `spellOnLetter: pitch class ${targetPitch} needs more than a double accidental on ${letter}`,
    );
  }
  const accidental = delta >= 0 ? "#".repeat(delta) : "b".repeat(-delta);
  return `${letter}${accidental}` as SpelledNote;
}

/**
 * Spell a diatonic scale using all 7 letter names, with accidentals
 * (#, b, ##, bb) as needed. The root's letter anchors the cycle.
 */
export function spellScale(
  root: SpelledNote,
  intervals: readonly number[],
): SpelledNote[] {
  const rootLetterIdx = LETTERS.indexOf(root[0] as Letter);
  const rootPitch = getNoteIndex(root);
  return intervals.map((interval, i) =>
    spellOnLetter(LETTERS[(rootLetterIdx + i) % 7], (rootPitch + interval) % 12),
  );
}

/**
 * Spell a chord stacked in thirds: chord tone i sits on the letter 2·i steps
 * above the root's letter, with accidentals added until it reaches
 * root + intervals[i]. Throws when a tone would need more than a double
 * accidental.
 */
export function spellChord(
  root: SpelledNote,
  intervals: readonly number[],
): SpelledNote[] {
  const rootLetterIdx = LETTERS.indexOf(root[0] as Letter);
  const rootPitch = getNoteIndex(root);
  return intervals.map((interval, i) =>
    spellOnLetter(LETTERS[(rootLetterIdx + 2 * i) % 7], (rootPitch + interval) % 12),
  );
}
```

Then change `buildDiatonicSpellingMap` (same file) to:

```ts
export function buildDiatonicSpellingMap(
  root: SpelledNote,
  intervals: readonly number[],
): ReadonlyMap<number, SpelledNote> {
  const rootPitch = getNoteIndex(root);
  const spelled = spellScale(root, intervals);
  const map = new Map<number, SpelledNote>();
  intervals.forEach((iv, i) => {
    map.set((rootPitch + iv) % 12, spelled[i]);
  });
  return map;
}
```

```ts
import { ALL_NOTES_KEY } from "../components/KeySelector";
import {
  getModalDiatonicChords,
  getModalDiatonicTriads,
  MODE_INTERVALS,
  type Mode,
} from "./modes";
import { CHROMATIC_SCALE, getNoteIndex, spellChord, type SpelledNote } from "./notes";
import type { ChordQuality, TriadQuality } from "./scales";

export type ChordRowMode = "triads" | "sevenths";

export type ChordTier = "secondary" | "diatonic" | "borrowed";

// degree is 1-7. For the secondary tier it is the degree of the target chord
// (V7/ii has degree 2).
export type ChordRef = { tier: ChordTier; degree: number };

export type MapChord = {
  ref: ChordRef;
  romanNumeral: string; // "V7/ii", "V/ii", "♭VI", "iv"
  symbol: string; // "A7", "A", "Ab", "Fm"
  quality: TriadQuality | ChordQuality;
  notes: readonly SpelledNote[];
};

// The part of a chord that marker pipelines need. MapChord, DiatonicChord and
// DiatonicTriad all satisfy it.
export type ChordToneSource = Pick<MapChord, "quality" | "notes">;

// Always 7 entries per tier; null renders as an empty cell.
export type ChordMap = Record<ChordTier, (MapChord | null)[]>;

export const CHORD_TIERS: readonly ChordTier[] = ["secondary", "diatonic", "borrowed"];

// Semitones above the root for each chord tone, root first. The single
// source of truth for chord construction (chordShapes.ts imports it).
export const QUALITY_INTERVALS: {
  readonly [Q in TriadQuality]: readonly [number, number, number];
} & {
  readonly [Q in ChordQuality]: readonly [number, number, number, number];
} = {
  maj: [0, 4, 7],
  min: [0, 3, 7],
  dim: [0, 3, 6],
  maj7: [0, 4, 7, 11],
  m7: [0, 3, 7, 10],
  "7": [0, 4, 7, 10],
  m7b5: [0, 3, 6, 10],
};

// Modes with a major third borrow from the parallel Aeolian; modes with a
// minor third borrow from the parallel Ionian. Derived from the mode's third
// rather than hand-listed.
export function borrowSourceMode(mode: Mode): Mode {
  return MODE_INTERVALS[mode][2] === 4 ? "aeolian" : "ionian";
}

function diatonicChords(key: string, mode: Mode, rowMode: ChordRowMode) {
  return rowMode === "sevenths"
    ? getModalDiatonicChords(key, mode)
    : getModalDiatonicTriads(key, mode);
}

// Spells a chord on `root`; when a letter-correct spelling would need a
// triple accidental (e.g. D##7 in A# Lydian), respells from the sharp-form
// enharmonic root instead (E7).
function spellChordOrEnharmonic(
  root: SpelledNote,
  intervals: readonly number[],
): SpelledNote[] {
  try {
    return spellChord(root, intervals);
  } catch {
    return spellChord(CHROMATIC_SCALE[getNoteIndex(root)], intervals);
  }
}

// Root a perfect fifth above `target`, on the letter 4 steps up when that
// spelling stays within double accidentals.
function fifthAbove(target: SpelledNote): SpelledNote {
  return spellChordOrEnharmonic(target, QUALITY_INTERVALS.maj)[2];
}

function buildSecondaryTier(
  key: string,
  mode: Mode,
  rowMode: ChordRowMode,
): (MapChord | null)[] {
  const targets = getModalDiatonicTriads(key, mode);
  return targets.map((target) => {
    if (target.degree === 1 || target.quality === "dim") return null;
    const quality = rowMode === "sevenths" ? "7" : "maj";
    const notes = spellChordOrEnharmonic(
      fifthAbove(target.notes[0]),
      QUALITY_INTERVALS[quality],
    );
    // Triad numerals carry no quality suffix for maj/min targets.
    const prefix = rowMode === "sevenths" ? "V7" : "V";
    return {
      ref: { tier: "secondary", degree: target.degree },
      romanNumeral: `${prefix}/${target.romanNumeral}`,
      symbol: rowMode === "sevenths" ? `${notes[0]}7` : notes[0],
      quality,
      notes,
    };
  });
}

export function getChordMap(key: string, mode: Mode, rowMode: ChordRowMode): ChordMap {
  const diatonic: MapChord[] = diatonicChords(key, mode, rowMode).map((c) => ({
    ref: { tier: "diatonic", degree: c.degree },
    romanNumeral: c.romanNumeral,
    symbol: c.symbol,
    quality: c.quality,
    notes: c.notes,
  }));

  const borrowed = diatonicChords(key, borrowSourceMode(mode), rowMode).map(
    (c, i): MapChord | null => {
      const own = diatonic[i];
      const sameRoot = getNoteIndex(c.notes[0]) === getNoteIndex(own.notes[0]);
      if (sameRoot && c.quality === own.quality) return null;
      return {
        ref: { tier: "borrowed", degree: c.degree },
        romanNumeral: c.romanNumeral,
        symbol: c.symbol,
        quality: c.quality,
        notes: c.notes,
      };
    },
  );

  return {
    secondary: buildSecondaryTier(key, mode, rowMode),
    diatonic,
    borrowed,
  };
}

export function resolveChordRef(
  ref: ChordRef,
  key: string,
  mode: Mode,
  rowMode: ChordRowMode,
): MapChord | null {
  if (key === ALL_NOTES_KEY) return null;
  if (!Number.isInteger(ref.degree) || ref.degree < 1 || ref.degree > 7) return null;
  return getChordMap(key, mode, rowMode)[ref.tier][ref.degree - 1] ?? null;
}

export function sameChordRef(a: ChordRef | null, b: ChordRef | null): boolean {
  if (a === null || b === null) return a === b;
  return a.tier === b.tier && a.degree === b.degree;
}

// Click/keyboard selection rule: picking the selected chord again clears it.
export function toggleChordRef(prev: ChordRef | null, next: ChordRef): ChordRef | null {
  return sameChordRef(prev, next) ? null : next;
}
```

```ts
export const HIGHLIGHTABLE: ReadonlySet<NoteDisplayRole> = new Set<NoteDisplayRole>([

// Resolves the visual role of a note given an optional chord context.
// - With a chord: returns the chord-relative role ('root'/'third'/'fifth'/
//   'seventh'), or 'scale' if the note is not a chord tone.
// - Without a chord: returns 'scale'. Deselecting the chord card is the
//   user-facing "clear highlights" shortcut — every in-key note falls back to
//   the plain scale role, and Legend toggles have nothing to demote.
// Matching is by pitch class, so enharmonic spellings resolve the same way.
export function roleFromChordTone(
  note: string,
  chord: Pick<ChordToneSource, "notes"> | null,
): NoteDisplayRole {
  if (!chord) return "scale";
  const noteIdx = getNoteIndex(note);
  if (noteIdx === getNoteIndex(chord.notes[0])) return "root";
  if (noteIdx === getNoteIndex(chord.notes[1])) return "third";
  if (noteIdx === getNoteIndex(chord.notes[2])) return "fifth";
  if (chord.notes.length === 4 && noteIdx === getNoteIndex(chord.notes[3])) {
    return "seventh";
  }
  return "scale";
}

export type KeyChordSpelling = {
  // Key/mode spelling per pitch class (the 7 in-key pitch classes only).
  key: ReadonlyMap<number, SpelledNote>;
  // The chord's own spelling per pitch class (empty without a chord).
  chord: ReadonlyMap<number, SpelledNote>;
  // Letters of out-of-key chord tones. An in-key, non-chord note on one of
  // these letters is hidden (C is hidden when A7 contributes C#).
  clashingLetters: ReadonlySet<string>;
};

export function buildKeyChordSpelling(
  key: string,
  mode: Mode,
  chord: Pick<ChordToneSource, "notes"> | null,
): KeyChordSpelling {
  const keyMap = buildDiatonicSpellingMap(key as SpelledNote, MODE_INTERVALS[mode]);
  const chordMap = new Map<number, SpelledNote>();
  const clashingLetters = new Set<string>();
  for (const note of chord?.notes ?? []) {
    const pc = getNoteIndex(note);
    chordMap.set(pc, note);
    if (!keyMap.has(pc)) clashingLetters.add(note[0]);
  }
  return { key: keyMap, chord: chordMap, clashingLetters };
}

// Decides whether the note at pitch class `pc` renders, and how it is
// labelled. Chord tones always render with the chord's spelling; other
// in-key notes render with the key's spelling unless their letter clashes
// with an out-of-key chord tone; everything else is dropped (null).
export function spellKeyOrChordTone(
  pc: number,
  spelling: KeyChordSpelling,
): { label: SpelledNote; isOutsideKey: boolean } | null {
  const chordLabel = spelling.chord.get(pc);
  const keyLabel = spelling.key.get(pc);
  if (chordLabel !== undefined) {
    return { label: chordLabel, isOutsideKey: keyLabel === undefined };
  }
  if (keyLabel === undefined) return null;
  if (spelling.clashingLetters.has(keyLabel[0])) return null;
  return { label: keyLabel, isOutsideKey: false };
}

  if (HIGHLIGHTABLE.has(role) && !enabledHighlights.has(role as HighlightableRole)) {
    return "scale"; // Legend toggle off → demote
  }
  return role;

  // Optional — defaults to 'ionian', preserving existing behavior. When
  // 'ionian', the in-mode check, parent-major anchoring, and characteristic
  // overlay all degrade to identical output of the pre-modal pipeline.
  mode?: Mode;
};

// Pure function: given the Chord-Tones view's full input, returns the
// NoteMarker[] that the Fretboard should render. Mirrors the pipeline
// described in the spec under "Marker Computation".
//
// Returns [] when:
// - key is the "All Notes" sentinel (the chord-tones concept requires a key)
// - positions is empty (the view's identity is the box; no box, no markers)
//
// A fret is "in window" if it falls in ANY of the selected positions. When
// showContext=true, notes outside the union of windows render with role
// 'muted' (faint context); when false, they're dropped entirely.
//
// Chord tones outside the key/mode (secondary dominants, borrowed chords)
// are kept, labelled with the chord's spelling and flagged isOutsideKey.
//
// In modal mode (mode !== 'ionian'), position windows are anchored on the
// parent major's tonic (parentMajorOf), and notes flagged by
// getCharacteristicNotes are stamped with isCharacteristic=true.
export function buildChordToneMarkers({
  tuning,
  key,
  chord,
  positions,
  showContext,
  enabledHighlights,
  enabledStrings,
  startFret,
  endFret,
  mode = "ionian",
}: BuildChordToneMarkersInput): NoteMarker[] {
  if (key === ALL_NOTES_KEY) return [];
  if (positions.length === 0) return [];

  const parentKey = parentMajorOf(key, mode);
  const characteristicSet = getCharacteristicNoteIndexSet(key, mode);
  const spelling = buildKeyChordSpelling(key, mode, chord);

  const result: NoteMarker[] = [];

  for (let stringIndex = 0; stringIndex < tuning.strings.length; stringIndex++) {
    const openString = tuning.strings[stringIndex];
    for (let fret = startFret; fret <= endFret; fret++) {
      const note = getNoteAtFret(openString, fret);
      const pc = getNoteIndex(note);
      const spelled = spellKeyOrChordTone(pc, spelling);
      if (spelled === null) continue;

      const inWindow = positions.some((p) =>
        isInPositionWindow(parentKey, p, fret, startFret, endFret, tuning),
      );
      if (!inWindow && !showContext) continue; // hide outside-position notes

      let role = demoteDisabledRole(roleFromChordTone(note, chord), enabledHighlights);
      if (!inWindow) {
        role = "muted"; // outside-window context override
      }

      const finalRole = enabledStrings.has(stringIndex) ? role : "muted";

      result.push({
        string: stringIndex,
        fret,
        note: spelled.label,
        role: finalRole,
        ...(characteristicSet.has(pc) ? { isCharacteristic: true } : {}),
        ...(spelled.isOutsideKey ? { isOutsideKey: true } : {}),
      });
    }
  }

  return result;
}

export type BuildNoteMapMarkersInput = {
  tuning: Tuning;
  key: string;
  mode: Mode;
  accidentalStyle: AccidentalStyle;
  chord: ChordToneSource | null;
  enabledHighlights: ReadonlySet<HighlightableRole>;
  enabledStrings: ReadonlySet<number>;
  startFret: number;
  endFret: number;
};

// Note Map pipeline. With the "All Notes" key every fret renders as a plain
// scale note spelled by accidentalStyle. With a key, in-key notes and the
// selected chord's tones render exactly as in buildChordToneMarkers, minus
// the position windows.
export function buildNoteMapMarkers({
  tuning,
  key,
  mode,
  accidentalStyle,
  chord,
  enabledHighlights,
  enabledStrings,
  startFret,
  endFret,
}: BuildNoteMapMarkersInput): NoteMarker[] {
  const showAll = key === ALL_NOTES_KEY;
  const characteristicSet = showAll
    ? new Set<number>()
    : getCharacteristicNoteIndexSet(key, mode);
  const spelling = showAll ? null : buildKeyChordSpelling(key, mode, chord);

  const result: NoteMarker[] = [];
  for (let stringIndex = 0; stringIndex < tuning.strings.length; stringIndex++) {
    const openString = tuning.strings[stringIndex];
    for (let fret = startFret; fret <= endFret; fret++) {
      const note = getNoteAtFret(openString, fret);
      const pc = getNoteIndex(note);

      let label: string;
      let role: NoteDisplayRole;
      let isOutsideKey = false;
      if (spelling === null) {
        label = getDisplayName(note, key, accidentalStyle);
        role = "scale";
      } else {
        const spelled = spellKeyOrChordTone(pc, spelling);
        if (spelled === null) continue;
        label = spelled.label;
        isOutsideKey = spelled.isOutsideKey;
        role = demoteDisabledRole(roleFromChordTone(note, chord), enabledHighlights);
      }

      result.push({
        string: stringIndex,
        fret,
        note: label,
        role: enabledStrings.has(stringIndex) ? role : "muted",
        ...(characteristicSet.has(pc) ? { isCharacteristic: true } : {}),
        ...(isOutsideKey ? { isOutsideKey: true } : {}),
      });
    }
  }
  return result;
}
```

```tsx
  maj7: "border-line-emphasis bg-surface-raised",
  m7: "border-line bg-surface-raised",
  "7": "border-line bg-surface-raised",
  m7b5: "border-line bg-surface-raised",
  maj: "border-line-emphasis bg-surface-raised",
  min: "border-line bg-surface-raised",
  dim: "border-line bg-surface-raised",
};

const QUALITY_NAMES: Record<ChordQuality | TriadQuality, string> = {
  maj7: "major seventh",
  m7: "minor seventh",
  "7": "dominant seventh",
  m7b5: "half-diminished",
  maj: "major triad",
  min: "minor triad",
  dim: "diminished triad",
};

function idleClasses(tier: ChordTier, chord: MapChord): string {
  if (tier === "secondary") return "border-dashed border-line-emphasis bg-surface";
  if (tier === "borrowed") return "border-mode/60 bg-surface-raised";
  return QUALITY_ACCENT[chord.quality];
}

export function ChordMapCard({
  chord,
  isSelected,
  onSelect,
  onAdd,
}: ChordMapCardProps) {
  const { tier, degree } = chord.ref;
  return (
    <div className="relative flex flex-col items-stretch gap-1">
      <button
        type="button"
        data-testid="chord-card"
        data-tier={tier}
        data-degree={degree}
        aria-pressed={isSelected}
        aria-label={`${chord.romanNumeral} ${chord.symbol}`}
        onClick={() => onSelect(chord.ref)}
        title={`${chord.romanNumeral} — ${chord.symbol} (${QUALITY_NAMES[chord.quality]}): ${chord.notes.join(", ")}`}
        className={`flex flex-col items-center justify-center gap-1 md:gap-1.5 px-1 py-2 md:px-3 md:py-4 md:min-h-[6.5rem] rounded-xl border-2 shadow-sm cursor-pointer transition-colors active:scale-[0.98] ${
          isSelected
            ? `${tier === "secondary" ? "border-dashed " : ""}border-line-selected bg-surface-active ring-2 ring-selection ring-inset`
            : `${idleClasses(tier, chord)} hover:border-line-hover`
        }`}
      >
        <span className="text-xs text-fg-muted font-mono font-semibold">
          {chord.romanNumeral}
        </span>
        <span className="text-sm md:text-xl font-bold text-fg-emphasis leading-none">
          {chord.symbol}
        </span>
        <span className="hidden md:block text-xs md:tracking-wider text-fg-secondary font-medium">
          {chord.notes.join(" – ")}
        </span>
      </button>
      {onAdd && (
        <button
          type="button"
          aria-label={`Add ${chord.symbol} to progression`}
          onClick={() => onAdd(chord.ref)}
          className="absolute top-1 right-1 w-6 h-6 rounded-full text-xs font-bold bg-surface-active text-fg-secondary hover:text-fg-emphasis cursor-pointer"
        >
          ＋
        </button>
      )}
      {tier === "secondary" && (

          ↓
        </span>
      )}
    </div>

}
```
